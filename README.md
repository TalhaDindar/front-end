Healthcare Access Smart Appointment System — Front-End

The React-based frontend for the Healthcare Access Smart Appointment System, built as part of a group project at North West University. This is the client-side application that NWU Health Centre students interact with to book healthcare appointments online.

The backend for this project lives here: Healthcare-Access-Smart-Appointment-System-Backend


The Problem

Students at the NWU Health Centre faced long queues and difficulty accessing healthcare services efficiently. This system was designed to streamline the process — allowing students to book appointments online rather than queuing in person.
